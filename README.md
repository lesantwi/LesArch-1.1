# LesArch

> **🏛️ Mapping Archaeological Wonders** — interactive maps, citable 3D reconstructions, and open research data.
>
> 🌐 **Live:** https://lesantwi.github.io/LesArch-1.1/

The source code for the [LesArch](https://lesantwi.github.io/LesArch-1.1/) website lives in the [`frontend/`](frontend/) folder and is built with [Astro](https://astro.build/).

## Quick start

```bash
cd frontend
yarn install
yarn dev          # http://localhost:3000
yarn build        # builds to frontend/dist
```

## Deployment

This repo deploys automatically to GitHub Pages on every push to `main` via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

**One-time setup:** Go to **Settings → Pages → Build and deployment → Source: "GitHub Actions"**.
